# PocketRT

放射線治療に従事する医療専門職向けの iOS アプリです。線量換算と治療スケジュールの確認を、手元で行うためのツールです。

> **⚠️ 免責事項**
>
> 本アプリは**教育および参考を目的**としたツールです。診断または治療の判断を行うものではありません。
>
> 表示される計算結果は、線形二次（LQ）モデルなどの数理モデルに基づく参考値であり、個々の症例における妥当性を保証するものではありません。**臨床上の判断は、各施設のプロトコルおよび担当医の責任において行われる必要があります。**
>
> 本アプリは薬機法上の医療機器には該当しません。

## 機能

| タブ | 内容 |
|---|---|
| 計算 | BED / EQD2 の算出、線量分割プリセットの適用、計算式の表示 |
| 合算 | 最大 3 コースの BED / EQD2 累積、再照射時の注意喚起 |
| 換算 | OAR 制約の分割数換算（分割数指定 / 1 回線量指定の 2 モード） |
| 予定 | 開始日から終了予定日・進捗・直近のスケジュールを算出。日本の祝日に対応 |

内蔵プリセットは線量分割 23 件、α/β 値 8 件。国内外のガイドラインおよび臨床試験（JCOG0403、JCOG0702、CHHiP、FAST-Forward、START-B、RTOG 90-05、JLGK0901、PACE-B 等）に基づいています。祝日データは内閣府公表の syukujitsu.csv に準拠しています（2024–2030）。

## 開発について

本アプリは、放射線治療医 1 名が生成 AI コーディング支援（Claude Code）を用いて開発した試作です。開発の経緯と評価は、日本医学放射線学会 秋期臨床大会 2026 で発表予定です。

計算カーネルはテスト駆動開発（TDD）で実装し、すべての計算式を文献値と照合して検証しています。検証内容は `PocketRTTests/` のテストコードに記述されています。

## 動作環境

- iOS 18.0 以降
- 外部依存ライブラリなし（Swift 標準ライブラリと SwiftUI のみ）

## ビルド

[xcodegen](https://github.com/yonaskolb/XcodeGen) が必要です。

```bash
brew install xcodegen
xcodegen generate
open PocketRT.xcodeproj
```

テストの実行:

```bash
xcodebuild -project PocketRT.xcodeproj \
           -scheme PocketRT \
           -destination 'platform=iOS Simulator,name=iPhone 17' \
           CODE_SIGNING_ALLOWED=NO \
           test
```

## プライバシー

本アプリは利用者の情報を一切収集せず、ネットワーク通信も行いません。入力値はすべて端末内で処理されます。

詳細は[プライバシーポリシー](https://yhi264.github.io/pocketrt/)を参照してください。
