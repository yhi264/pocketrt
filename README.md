# PocketRT

[![CI](https://github.com/yhi264/pocketrt/actions/workflows/ci.yml/badge.svg)](https://github.com/yhi264/pocketrt/actions/workflows/ci.yml)

放射線治療に従事する医療従事者向けの iOS アプリです。線量換算と治療スケジュールの確認を、手元で行うためのツールです。

> **⚠️ 免責事項**
>
> 本アプリは**教育および参考を目的**としたツールです。診断または治療の判断を行うものではありません。
>
> 表示される計算結果は、線形二次（LQ）モデルなどの数理モデルに基づく参考値であり、個々の症例における妥当性を保証するものではありません。**臨床上の判断は、各施設のプロトコルおよび担当医の責任において行われる必要があります。**
>
> 本アプリは医療機器としての承認または認証を受けたものではありません。

## 機能

| タブ | 内容 |
|---|---|
| 計算 | BED / EQD2 の算出、線量分割プリセットの適用、計算式の表示 |
| 合算 | 最大 3 コースの BED / EQD2 累積、再照射時の注意喚起 |
| 換算 | OAR 制約の分割数換算（分割数指定 / 1 回線量指定の 2 モード） |
| 予定 | 開始日から終了予定日・進捗・直近のスケジュールを算出。日本の祝日に対応。治療期間全体を見る 3 ヶ月カレンダー |
| 品質 | SBRT / SRS のプラン品質指標（CI・HI・R50%・GI・D2cm）を算出し、公表プロトコルの適合性判定表と照合 |

各タブの右上の ⓘ から、計算式・α/β 値の根拠・プリセットの出典・免責事項を確認できます。

内蔵プリセットは線量分割 18 件、α/β 値 8 件。**JASTRO 放射線治療計画ガイドライン 2020 に明記されていること**を採用基準とし、裏付けとなる臨床試験（JCOG0403、JROSG10-1、CHHiP、START-B、RTOG 90-05、Bone Pain Trial 等）の書誌情報を併記しています。臨床試験の裏付けがあっても、ガイドラインに明記されていない線量分割は原則として収録していません。例外は乳癌超寡分割（FAST-Forward 26 Gy/5 回）の 1 件で、主要報告が 2020 年でありガイドラインに反映されていないだけと判断して残しています。採用と削除の判断の経緯は `docs/data-sources.md` に記録しています。祝日データは内閣府公表の syukujitsu.csv に準拠しています（2024–2030）。

### 数値と出典の追跡可能性

アプリが表示する数値・引用がどこから来たかは [`docs/data-sources.md`](docs/data-sources.md) に記録しています。適合性判定表の原典からの転記手順と誤植の補正根拠、各プリセットの一次文献（PMID / DOI）、および**一次文献を同定できなかったレジメンをそれと明示する方針**を含みます。

推測で出典や数値を補うことはしていません。同定できなかったものは「広く用いられる慣用レジメン。特定の一次文献に基づかない」とアプリ内に表示され、PMID は付きません。

## 開発について

本アプリは、放射線治療医 1 名が生成 AI コーディング支援（Claude Code）を用いて開発した試作です。開発の経緯と評価は、第62回日本医学放射線学会秋季臨床大会（2026年9月、旭川）で発表予定です。

計算カーネルはテスト駆動開発（TDD）で実装し、すべての計算式を文献値または手計算と照合して検証しています。現在 **104 件 / 18 スイート**。検証内容は `PocketRTTests/` のテストコードに記述されており、CI で毎回実行されます。

## 動作環境

- iOS 18.0 以降
- 外部依存ライブラリなし（Swift 標準ライブラリと SwiftUI のみ）

## ビルド

[xcodegen](https://github.com/yonaskolb/XcodeGen) が必要です。

```bash
brew install xcodegen
xcodegen generate
open PocketRT.xcodeproj
```

テストの実行:

```bash
xcodebuild -project PocketRT.xcodeproj \
           -scheme PocketRT \
           -destination 'platform=iOS Simulator,name=iPhone 17' \
           CODE_SIGNING_ALLOWED=NO \
           test
```

## プライバシー

本アプリは利用者の情報を一切収集せず、ネットワーク通信も行いません。入力値はすべて端末内で処理されます。

詳細は[プライバシーポリシー](https://yhi264.github.io/pocketrt/)を参照してください。
